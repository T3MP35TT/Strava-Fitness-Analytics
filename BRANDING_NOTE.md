# Branding Note

The current analytical notebook loads files named `dailyActivity_merged.csv`, `dailyCalories_merged.csv`, `dailyIntensities_merged.csv`, and related Fitbit-format files. The project should therefore use neutral fitness/health analytics branding unless the data provenance is changed to Strava.

The UI uses an orange fitness-industry accent and explicitly states that it is an independent analytics application, not affiliated with Strava.

If the project is later connected to the Strava API, the official **Powered by Strava** or **Compatible with Strava** attribution asset can be added according to Strava's current API Brand Guidelines. The Strava logo should not be used as the application's own icon or in a way that implies endorsement.
